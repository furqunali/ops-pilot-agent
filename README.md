# 🛠️ OpsPilot — AI Operations Agent

**OpsPilot** is an AI operations copilot: an agent designed to take natural-language operational instructions and carry out routine back-office and workflow tasks. Started as a **Hackathon 2** build and structured for spec-driven, instruction-led automation.

> 🚧 **Work in progress.** This repo holds the project structure and agent specification; the implementation is being built out.

## Structure

- **`agent-instructions.md`** — the agent's operating spec: role, guardrails, and how it should act
- **`examples.md`** — sample tasks and the expected agent behaviour
- **`src/`** — application code

## Vision

An operations-focused **Digital FTE**: describe a task in plain language, and OpsPilot plans and executes it against connected tools — cutting manual, repetitive ops work. Aligned with my broader work on AI agents and intelligent automation.
